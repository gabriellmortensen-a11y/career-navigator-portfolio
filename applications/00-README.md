## What changed since Application layer 3.0

The 2026-07-08 Application layer had 14 documents describing standards for many artifacts:
- résumés and cover letters;
- an executive biography;
- recruiter outreach and networking;
- interview guides and preparation packages;
- opportunity analysis and application packages;
- promotion packets, performance-review support and reflection;
- application analytics.

| 3.0 described | 4.0 status |
|---|---|
| Résumé generation standard | **Built, then rebuilt several times.** Now the recruiter-selects flow (03) |
| Interview preparation package | **Built** (05); since 5.0 led by the interview coach |
| Opportunity analysis | **Built** as Chart My Course (01) |
| Networking | **Partly**: connections import, "who you know there", a message draft (04). No outreach tracking |
| Application package | **Built in a narrower form**: apply kits for Greenhouse forms (04); since 5.0 the application chat helps answer any form's questions |
| Application analytics | **Partly**: status history and an activity card (04). No outcome analytics |
| Cover letter | **Only as a kit or application-chat answer** drafted from evidence, never a standalone artifact |
| Executive biography, promotion packet, performance-review support, reflection & learning | **Never built** ([D-24](../evidence/05-discrepancies.md#d-24)) |
| — | **New since 3.0:** gap conversations (02), job discovery (04), company research (05), career conversation links (the living résumé since 2026-10-31) and the ChatGPT connector (06); in 5.0 the interview coach (05), the application chat (04) and Navi (07) |

3.0 said "Applications are not documents. Applications are experiences." 4.0 adds what using it
taught: **the experience is a sequence of human decisions** (assess, close gaps, write, apply,
submit), and **the system's job is to make each decision cheap and well-informed, never to take it.**
