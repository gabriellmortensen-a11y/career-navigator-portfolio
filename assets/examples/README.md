# Examples

Every example here is either **verbatim system text that holds no personal data**, an **aggregate of
telemetry**, or **explicitly synthetic**. None contains a career record, a job posting from my
search, an employer name, or any account identifier.

| File | Kind | What it shows |
|---|---|---|
| [resume-flow-prompts.md](resume-flow-prompts.md) | Verbatim governed policy text (Live `7322289`) | The selector answers with numbers only; the writer's template has no slot for requirements; bullets carry their story number |
| [model-assignment-excerpt.md](model-assignment-excerpt.md) | Verbatim governed document excerpt | Model routing as a versioned document, each choice with its evidence and sample size |
| [resume-run-phases.json](resume-run-phases.json) | Aggregate Live telemetry (32 runs, one account) | Per-phase cost, time and calls of a résumé run |
| [synthetic-evidence-walkthrough.md](synthetic-evidence-walkthrough.md) | Synthetic (invented person and posting), real data shapes | One requirement from evidence entry to an attributed bullet, and what would or would not be caught |

**Why there are no screenshots.** The only accounts with real product pages are real career records.
The baseline's publication rules forbid screenshots of a real record, so the diagrams in
[architecture/](../../architecture/00-README.md) carry the visual explanation instead.
